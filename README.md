📖 Про проєкт
Цей навчальний проєкт створено в рамках навчальної дисципліни «Програмне забезпечення ПК» (Розділ ІІ, Практична робота №3). Головна мета — надати зручний та доступний інтерфейс для перегляду інформації про навчальні проєкти, розклад та канали зворотного зв'язку, а також продемонструвати високі стандарти оформлення проєктної документації у форматі Markdown.

Ключові цілі:
Забезпечення швидкого доступу до контактної інформації та відомостей про розробника.
Демонстрація чистої та валідної семантичної верстки за стандартами W3C.
Застосування кращих практик документування коду (Open Source Documentation Standards).
✨ Основні можливості
📱 Адаптивний дизайн: комфортний перегляд на пристроях з будь-якою роздільною здатністю (ПК, ноутбуки, планшети, смартфони).
🧩 Модульна структура: чітке розділення розмітки (index.html) та стилів оформлення (css/style.css).
📞 Інтерактивний блок контактів: виділена секція з номерами гарячої лінії, адресами електронної пошти та робочим графіком.
⚡ Нульова залежність від важких фреймворків: миттєве завантаження та висока енергоефективність.

🚀 Встановлення
Для того щоб розгорнути проєкт локально на своєму комп'ютері:

Переконайтеся у наявності встановленого Git:

bash

git --version
Склонуйте репозиторій на свій комп'ютер:

bash

git clone https://github.com/dmitrovojtovic23-lab/PracticeWork2.git
Перейдіть у каталог проєкту:

bash

cd PracticeWork2
(Додаткових сторонніх залежностей або менеджерів пакетів проєкт не потребує, оскільки написаний на чистому HTML/CSS).

💻 Використання
Запустити веб-портал можна одним із зручних варіантів:

Варіант А. Пряме відкриття у браузері
У середовищі Windows (PowerShell):
powershell

Start-Process index.html
У середовищі macOS / Linux:
bash

open index.html      # macOS
xdg-open index.html  # Linux
Варіант Б. Запуск через вбудований локальний сервер Python
bash

python -m http.server 8000
Після запуску відкрийте браузер за адресою: http://localhost:8000

Варіант В. Запуск через Node.js (npx)
bash

npx serve .
